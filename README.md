# Python Fundamentos

Material introdutório de estudos e exercícios práticos sobre fundamentos da linguagem Python.

## Conteúdos

O arquivo principal apresenta exemplos de:

- comentários e saída com `print`;
- variáveis e tipos primitivos;
- formatação de textos;
- operadores aritméticos, lógicos e relacionais;
- conversão de tipos (*casting*);
- entrada de dados com `input`;
- operações e manipulação de strings;
- exercícios de fixação.

## Requisitos

- Python 3.8 ou superior.

O projeto utiliza apenas a biblioteca padrão do Python e não requer dependências externas.

## Como executar

```bash
python3 python_fundamentos.py
```

O programa contém vários exemplos interativos e solicitará dados pelo terminal em determinados trechos.

## Observação

Este projeto tem finalidade educacional. Os valores e respostas presentes nos exercícios são exemplos para acompanhar o aprendizado e podem ser alterados livremente.
